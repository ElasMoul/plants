Herbarium

The design system PlantPal is built from. Named for the practice it borrows: press the specimen, label it in a patient hand, number the plate, and keep it — calm, exact, and honest about what it does not know.

Stable v1.0.0 Four layers

What this system is

Herbarium is four layers, each written against the one below it. Principles decide anything the other layers leave open. Tokens hold every colour, size, type role and duration — primitives naming raw values, semantics naming what those values mean. Components are the product's vocabulary, every class prefixed hbm-. Patterns are the assembled surfaces: traverse the garden, live with uncertainty, see what is due today. The exact page set is declared once, in constitution.json.

The visual signature comes from the world of living plants and the practice of tending them — herbarium sheets, botanical plates, nursery plant tags, field notebooks, the diffuse light of a windowsill — and from nothing else. Soil and terracotta, chlorophyll green through chlorosis yellow to necrotic brown, hairline rules and a great deal of margin. There are no dark-mode neon gradients here, no particle fields, no telemetry chrome.

Principles

Six rules govern every token, component and page. Read them in full in PRINCIPLES.md, the system's constitution.

  1. Paper, not console

    A warm sheet under windowsill light. Colour enters only where it carries meaning; a shadow is a specimen lifted a millimetre off the mount, never a glow in a dark room.

  2. Say so when unsure

    Confidence is drawn at the same weight as the claim it qualifies. Unloaded is not empty, stale says how stale, and a failure is a state inside the thing that failed.

  3. Every edge is visible before it is taken

    Navigation is drawn as a directed edge; mutation is drawn as a filled stake. You can tell them apart by form, before touching either.

  4. The place holds still

    One world, one you-are-here marker, positions computed once and kept. Adding a plant does not move the plants already there.

  5. Growth, not sliding

    Things unfurl and travel; nothing fades, pops or teleports. Under reduced motion the distance is still shown — it is simply crossed at once.

  6. Domestic language, beginner's footing

    My garden, nickname, due today. Latin is information the system offers, never a demand. Type sits on a five-step ladder so hierarchy survives a blur.

The system in one specimen

A plant tag carries what a garden-centre stake carries, plus the two things PlantPal always adds: how the plant is doing, and how sure the system is.

Navigation and mutation are never confusable

This is the rule the rest of the system is built around: a user must know whether something will take them somewhere or change their garden, from its form alone, before activating it.

Do
Monstera

Draw a destination as an edge with a direction, and a mutation as a filled action that offers its reversal in place.

Don't

Give a destination and a mutation the same form — the user cannot tell which one changes their plant.

Using this system

Load the three stylesheets in order, then the two scripts. Nothing else is required — there is no build step and no dependency.

<link rel="stylesheet" href="assets/tokens.css">
<link rel="stylesheet" href="assets/system.css">
<link rel="stylesheet" href="assets/docs.css">

<script src="assets/system.js"></script>
<script src="assets/docs.js"></script>

Before you write a page

Read assets/AUTHORING.md end to end. It is the contract every page in this site is written against: the exact skeleton, the four canonical blocks, and the finishing checklist. The asset layer is frozen for v1.0.0 — pages consume it and never change it.
