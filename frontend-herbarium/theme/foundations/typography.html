Foundations

Typography

Three families, six size rungs, six type roles. Set type with a role token and the hierarchy comes out right without you choosing a size.

Stable v1.0.0

Overview

Herbarium sets type the way a specimen sheet is labelled: a serif for anything a person reads as a name or a claim, a plain sans for the running text they read at speed, and a monospace for the small ruled labels that index the sheet. The register is paper, not console — so nothing shouts, and prominence comes from scale rather than from weight or colour.

Use a type role token — --hbm-font-body, --hbm-font-heading — or the class that carries it. Roles bundle family, size, weight and line height in one value, so a heading cannot drift a rung out of step with the rest of the system. Reach past a role to a bare size only inside a component that already exists in system.css; a page never does it.

Blur the screen until the words are unreadable. If you can still tell which line is the plant's name, which is its care fact and which is the plate index, the type is doing its job. If you cannot, no amount of colour will fix it — see the six principles.

Families

Each family has one job. Never swap them for effect: a plant nickname in monospace reads as a serial number, and a plate index in the serif reads as prose.

TokenStackUse
--hbm-family-plate Iowan Old Style, Palatino, Georgia, Noto Naskh Arabic, serif Names and claims — display, title, heading, and every Latin binomial.
--hbm-family-hand system-ui, Segoe UI, Inter, Noto Sans Arabic, sans-serif Everything you read at reading speed — body copy, captions, care facts, log entries.
--hbm-family-label ui-monospace, Cascadia Mono, Menlo, Consolas, monospace Ruled small-caps labels, plate numbers, field labels, code.

Both text families name an Arabic face before the generic fallback, so an Arabic screen keeps the same serif-versus-sans distinction rather than collapsing into one system font. Do not add a family; if a screen seems to need a fourth, it needs a different role instead.

The size ladder

Six rungs, numbered by prominence rather than by pixels, so the number tells you where a line sits in the hierarchy. The gaps between neighbouring rungs are wide on purpose — two rungs that look similar are two rungs too many.

TokenValueUse
--hbm-size-1003.25remDisplay — one per screen at most, usually a garden's own name.
--hbm-size-752.125remTitle — the focused plant, the thing you navigated to.
--hbm-size-551.4375remHeading — a sheet's title, a section within a plant.
--hbm-size-301remBody — the default. Never set running text below this.
--hbm-size-250.875remCaption — care facts, log bodies, secondary notes.
--hbm-size-180.75remLabel — uppercase ruled labels and plate numbers only, never a sentence.

Weight, leading and tracking

Weight carries almost nothing here. --hbm-weight-medium marks a name inside a dense row; --hbm-weight-bold is held in reserve and no role uses it. Line height widens as size shrinks, because a caption is read in a longer sweep than a title.

TokenValueUse
--hbm-weight-regular400Display, title, body, caption — the default everywhere.
--hbm-weight-medium500Headings, labels, and a name inside a node or edge row.
--hbm-weight-bold650Reserved. No role uses it; do not introduce one.
--hbm-leading-tight1.15Display and title, where lines are few and short.
--hbm-leading-snug1.35Headings, captions, labels, code.
--hbm-leading-body1.65Running text, so a paragraph stays easy to re-enter.
--hbm-tracking-plate0.01emThe page-wide default — a hair of air, as on printed plate copy.
--hbm-tracking-label0.14emUppercase labels only; uppercase needs the extra space to stay legible.

Measure

Line length is a type decision, so it lives here. Cap running prose at --hbm-measure-prose (68ch) and anything read beside a photo — a care fact, a log entry, a tag — at --hbm-measure-note (46ch). Past those widths the eye loses the start of the next line.

.my-page-note { max-width: var(--hbm-measure-note); }

Type roles

These six roles are what you actually write. Each is one font shorthand, and each has a matching class in system.css so a page rarely needs any CSS at all.

TokenClassComposition and use
--hbm-font-display.hbm-displaySerif, rung 100, tight. Once per screen.
--hbm-font-title.hbm-titleSerif, rung 75, tight. The focused thing's name.
--hbm-font-heading.hbm-headingSerif, rung 55, medium, snug. Sheet and section titles.
--hbm-font-body.hbm-bodySans, rung 30, body leading. The default; also the page default on body.
--hbm-font-caption.hbm-captionSans, rung 25, snug, secondary ink. Supporting text.
--hbm-font-label.hbm-labelMono, rung 18, medium, uppercase, label tracking, muted ink.

Two specialised roles

Two kinds of text carry meaning beyond their rung, so they have their own classes rather than a role you reassemble by hand.

.hbm-binomial is the only place a Latin name may appear. .hbm-plate-no is the collector's index — it identifies a specimen sheet, and it is never a heading. Both are demonstrated in place on Plant tag and Plate.

Type in context

Roles are meant to be read against each other, not in isolation. A plant tag stacks four of them — heading, binomial, label, body — inside 46ch, and stays readable because each step down the ladder is unmistakable.

When the system is unsure of a name, the hedge sits at caption weight beside it rather than shrinking the claim into fine print. Uncertainty is stated at the same size you read everything else — the full pattern is on Uncertainty.

Accessibility

Every size on the ladder is set in rem, so the whole system scales with the reader's browser or OS text size. Nothing is capped in pixels and html keeps -webkit-text-size-adjust: 100%, so a page enlarged to 200% reflows rather than clipping. Test at 200% before you call a page done.

Set running text at rung 30 or above. Rungs 25 and 18 are for supporting text and labels, and rung 18 is uppercase-only and never carries a sentence — uppercase strips the word shapes a reader with dyslexia relies on, and a long uppercase line is slow for everyone.

Body text at --hbm-text-primary and supporting text at --hbm-text-secondary both clear 4.5:1 against the sheet and mount surfaces in paper and dusk alike. --hbm-text-muted is the floor: use it only for label-sized text that repeats information available elsewhere, never for the only copy of a fact.

Choose heading levels by document structure, then set the look with a role class — the two are independent on purpose. A page has exactly one h1 and skips no levels; if an h2 should look smaller than its position implies, give it .hbm-caption rather than demoting it to an h3. Screen readers announce the level, not the size, and a skipped level strands a reader navigating by headings.

Text that exists only for screen readers uses .hbm-visually-hidden. It keeps the text in the accessibility tree; display: none and zero font sizes remove it.

<h2 class="hbm-caption">Recent scans<span class="hbm-visually-hidden"> in your garden</span></h2>

In Arabic and Hebrew the ladder is unchanged, but the serif and sans fall to their Arabic faces, which run taller than the Latin ones. Never set a fixed height on a line of type — let it grow. Full rules are on RTL & locale.

Usage guidance

Reach for a role first. If no role fits, the screen is asking for a hierarchy the system does not have, and the answer is to simplify the screen rather than to invent a size.

Do

Fern

Water every 5 days

Separate the name from its care fact by two full rungs, so the plant is identifiable before the sentence is read.

Don't

Fern

Water every 5 days

Set a name and its fact at the same rung — the reader has to read both lines to find out which one is the plant.

Do

Due today

Keep the label role for short ruled headings, where the wide tracking and uppercase help the eye find the section.

Don't

Three plants in your garden need attention before this evening

Run a sentence in the label role — uppercase at rung 18 is the slowest text in the system to read.

Rules

Use a role token, never a bare size, on a page. Use .hbm-binomial for every Latin name and nothing else. Cap running text at --hbm-measure-prose. Keep one display per screen. Set heading levels by structure and the look by role class.

Spacing between type is set by the space scale, not by margins you pick — see Spacing. What the words themselves say is on Voice & copy.
