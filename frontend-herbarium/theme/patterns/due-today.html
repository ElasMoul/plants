Patterns

Due today

Due today is the one short list PlantPal asks you to act on: the plants in your garden that want something from you before the day is out. It is a working sheet, not a warning — you read it standing next to the plant, tick things off, and put the phone down.

Stable v1.0.0

Overview

Every plant in my garden carries its own care schedule. Due today gathers the tasks whose date has arrived or passed, draws each one as a single line you can finish in one tap, and says how sure it is about each. When the list is empty it says so plainly and stops asking for your attention.

Use this pattern anywhere the day's care is summarised: the opening view of my garden, a bed you have walked into, a single plant's sheet. Use the same line shape in all three, so a task looks the same wherever you meet it.

Do not use it as an inbox of everything the app knows. Anything not actionable today belongs on the plant, not on this sheet. Do not use it for alerts about the app itself — an offline or failed state is drawn where it happened, which is covered in Uncertainty. The parts this pattern assembles are documented in Actions, Edges, Health & confidence and Care log.

The test for a line

A line belongs on today's sheet only if the user can finish it now, with the plant in front of them. If it needs a decision, a purchase or a wait, it is not due today — it is something the plant's own sheet should carry.

The day's sheet

The sheet names the day, counts what is on it, and then gets out of the way. Each line holds three things in a fixed order: an edge to the plant, its health, and the one action that clears the line. The plant's name is drawn as an edge because tapping it travels; the action is filled because it changes your garden. The two are never swapped.

Every line uses the same action weight. There is no primary action on this sheet — nothing here is more important than anything else, and giving one line a filled accent would say otherwise. Log a task below: the button holds your undo in place for a few seconds rather than moving you anywhere.

The count in the header names plants, not tasks, because that is what the user is about to walk to. It updates in place when a line is cleared; the sheet does not reflow, reorder or animate, so the line you just tapped is still under your thumb.

Late, and unsure

A task whose date has passed stays on the same sheet, in the same shape, with one extra mark: how long it has been waiting. Late is drawn in caution, never in danger — a plant that missed a watering is behind, not harmed. Reserve the harm tone for something that has actually damaged a plant.

When PlantPal is not sure a task is needed — the last scan was blurry, or the soil reading disagrees with the schedule — the line says so before it asks for the tap. A low-confidence claim carries its rungs and a hedge in the user's own words, so nobody waters a plant on a guess presented as a fact.

An unsure line keeps its action. Withholding the button would make the user hunt for another way to water a plant they can see is dry; the honest move is to say what is uncertain and let them decide.

A day with nothing on it

Most days have nothing due, and that is the pattern working. An empty sheet is a real, loaded answer — draw it as a place with room in it, and never as a region that failed to load. Hatching and dashes mean not known yet; they must not appear here.

The empty day offers one way onward, drawn as an edge, and asks for nothing.

Behaviour

States of a line

A line is in exactly one of these states, and each is drawn by a component that already exists. Do not invent a fourth mark for a fifth state.

StateHow it is drawnWhat the user can do
Due Plain line: edge, health, action. Log it, or travel to the plant.
Late .hbm-badge--caution naming how long it has waited. The same. Being late changes nothing about the tap.
Unsure .hbm-confidence--low with a .hbm-hedge in plain words. Check the plant, then log it or leave it.
Just logged The action holds an undo in place for a few seconds. Undo without leaving the sheet.
Stale .hbm-stale-note saying when it was last checked. Act on what is shown, knowing its age.

Keyboard

Tab reaches every line in reading order, and within a line reaches the name before the action — the destination before the change. Enter on the name travels; Enter or Space on the action logs the task and leaves focus on the button, where the undo now is. Nothing on this sheet is reachable only by pointer.

Motion and reduced motion

Clearing a line is a non-structural change, so nothing moves: the count updates in place, the button becomes its own undo, and the line keeps its position until the sheet is next loaded. Under prefers-reduced-motion the durations already collapse in tokens.css and the looping fill ornament stops; the marks themselves stay drawn, because they carry meaning that motion never did.

Accessibility

The count belongs in the heading region as text, not in the badge alone, so a screen reader announces the sheet as “Due today, 3 plants” on arrival. Give the sheet a heading at the level the surrounding page needs; do not skip levels to make it look smaller.

Every mark on a line has a text equivalent in the same line. The health leaf is decorative on its own — the word beside it (“Needs attention”) is what is announced. The confidence rungs are the same: the word “Low” is read, the rungs are not. Never let colour alone carry late, unsure or done; each already ships with a word.

When the button becomes its own undo, its label changes in place, so the accessible name changes with it and focus is never moved out from under the user. If a mark has no visible word — a bare count, an icon-only action — give it one with .hbm-visually-hidden.

<button type="button" class="hbm-act hbm-act--icon" data-hbm-undo="Watered Fern">
  <span class="hbm-visually-hidden">Log watering for Fern</span>
</button>

Contrast: the caution and confidence roles meet the text contrast requirement against the sheet surface in both paper and dusk, which is why they are used as ink rather than as fills. Do not tint a whole line to signal late — a large soft wash of caution loses that guarantee and reads as an alarm at the same time.

Focus is never removed. Each line's focus ring is drawn by the system at a width and offset that survives at any zoom, and the whole sheet is usable at 200% without a horizontal scroll, because a line wraps rather than truncating the plant's nickname.

Usage guidance

Two rules decide most of what goes wrong on this sheet: keep the two kinds of tap distinct, and keep lateness proportionate.

Do
Fern

Draw the plant as an edge and the task as a filled action, so the user knows which tap travels and which one changes their garden before they make it.

Don't

Give the plant's name the heaviest action on the sheet — it does not change anything, and the real task is now the quieter of the two.

Do
2 days late

Say how late a task is in caution, in words, so the user can judge whether it still matters today.

Don't
Overdue

Use the harm tone for a missed watering — it spends the one signal that should mean a plant is actually being damaged.

Keep the sheet short

If today's sheet runs past what fits on one screen, the schedule is wrong, not the list. Group repeated tasks by plant and let the rest wait — a list nobody can finish teaches the user to ignore it.

Two more rules, stated plainly. Never reorder the sheet while the user is working through it; a line that moves under a thumb becomes a mistaken tap. And never mark a task done on the user's behalf because time passed — a schedule predicts, only a person reports, and the difference is recorded in the Care log.
